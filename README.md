\# Wardrobee Lemari Digital dan Jadwal Outfit



Aplikasi mobile Jetpack Compose (MVVM) untuk mencatat pakaian yang sudah dimiliki dan mengatur outfit harian.



\## Teknologi

\- Kotlin, Jetpack Compose, MVVM, Navigation Compose

\- Retrofit untuk REST API

\- Database Postgres

\- Penyimpanan file lokal (jadwal outfit)
